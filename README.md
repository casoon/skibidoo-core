# skibidoo-core

Skibidoo e-commerce core — API, Worker and Scheduler.

**Website:** [skibidoo.casoon.de](https://skibidoo.casoon.de/en/)

## Part of the skibidoo e-commerce system

- [skibidoo-core](https://github.com/casoon/skibidoo-core) — backend API
- [skibidoo-storefront](https://github.com/casoon/skibidoo-storefront) — customer storefront
- [skibidoo-admin](https://github.com/casoon/skibidoo-admin) — admin dashboard
- [skibidoo-ui](https://github.com/casoon/skibidoo-ui) — UI components
- [skibidoo-docs](https://github.com/casoon/skibidoo-docs) — documentation
